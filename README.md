# Smooth Chunk Save

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_582327_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/582327.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Smooth Chunk Save is a lightweight minecraft mod which saves chunks continuously over time, reducing server lag and preventing lagspikes from saving too many chunks at once.

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.

> This mod is officially distributed only through CurseForge. Downloads from other websites may be outdated, modified, or unsafe.
